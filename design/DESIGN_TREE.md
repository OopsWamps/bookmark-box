## D5-2 展开（DEC-001/002 批准，REV1 已落地 2026-10-10）

安全功能必须分层，且相互独立（工程说明原文："副槽不能替代升降防坠、独立失电保持和检修支撑"）：

```
D5-2 升降方向安全 [AND — 三个子功能缺一不可]
├─ D5-2a 失电保持（正常停止后断电不下降）[OR]
│  ├─ A1 失电电磁抱闸（电机尾端，断电抱紧）[候选，推荐]
│  ├─ A2 梯形丝杠自锁 [候选，仅辅助] — igus 结论：自锁随摩擦/磨损/振动漂移，
│  │   不能作为独立保持；保留为降级备份而非答案
│  └─ A3 蜗轮自锁传动 [候选，替代 A1] — 效率低、发热；同样受自锁漂移质疑
├─ D5-2b 传动失效防坠（断带/螺母失效不坠落）[OR]
│  ├─ B1 常闭棘爪 + 固定棘条 [候选，推荐] — 失电（或断带触发）落下啮合，
│  │   与传动链完全独立；fail-safe；可三维演示
│  ├─ B2 楔块式安全钳夹导杆 [候选] — 需超速检测与夹紧力设计，对本机过重
│  └─ B3 行程端部挡块 [候选，仅最低限] — 只防坠到箱底，不防中间停止，
│      不能单独满足防坠，保留并入任何组合作为最后一级
└─ D5-2c 检修支撑（维护时人手下的机械支撑）[OR]
   ├─ C1 可翻转检修挡块（支撑车架底面，人工插入/翻出）[候选，推荐]
   └─ C2 检修撑杆（外置插入式）[候选] — 占用外部空间，易遗失
```
